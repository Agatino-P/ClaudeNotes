# 12 September 2026

*This week in Claude Code: `/resume` on desktop, start sessions from your phone, and more*

Full issue: [code.claude.com/docs/en/whats-new](https://code.claude.com/docs/en/whats-new) · [changelog](https://code.claude.com/docs/en/changelog)

This is an actionable extract, not a transcript — the config worth applying, the one breaking change, and the reference items. The official archive has the complete issue.

## Worth applying

### Per-model effort levels

`/effort` now remembers the level per model, saved under `modelSettings` in user settings. Set it once per model and switching with `/model` no longer means re-setting effort.

```json
// ~/.claude/settings.json
{
  "modelSettings": {
    "claude-fable-5-1": { "effortLevel": "medium" },
    "claude-opus-5":    { "effortLevel": "high" }
  }
}
```

Replaces a single flat `effortLevel` key, which applies to whatever model you happen to be on. On Fable 5.1, changing effort mid-session no longer invalidates the prompt cache (since 2.1.260).

### Default model for subagents

```json
// ~/.claude/settings.json
{
  "env": { "CLAUDE_CODE_SUBAGENT_MODEL": "opus" }
}
```

Useful when the main conversation runs on a model that spawns many subagents — the subagents can run somewhere cheaper or steadier while the main thread stays put. `/tasks` shows which model a running subagent is using.

### Find skills you never use

```
/skill-doctor
```

Reports what each skill costs in context and how often Claude actually invokes it, flagging the ones that never fire. Worth running when the skills list has grown. *(2.1.261)*

## Breaking change

### `bypassPermissions` no longer works in project settings

Claude Code now **ignores** `defaultMode: "bypassPermissions"` in a project's `.claude/settings.json`. It must live in `~/.claude/settings.json`, or be passed as `--permission-mode bypassPermissions`. *(2.1.257)*

Check any project that relied on it — it now fails silently rather than erroring.

## Relevant to a status line script

`/cost` now reports prompt-cache statistics: hit rate, misses, whether the cache is still warm, and (since 2.1.260) the likely cause of the last miss.

The same numbers reach a status line script in the payload's **`prompt_cache`** object — a candidate segment for [`../StatusLine/`](../StatusLine/) if cache behavior ever needs watching. *(2.1.251, 2.1.260)*

## Reference

**Added**

- **`/diff` panel** — in fullscreen mode (`/tui fullscreen`), `/diff` opens a panel beside the conversation showing every changed file with added/removed counts and the diff. Selecting lines in the panel attaches them to the next prompt. Needs 2.1.260+, a git repo, and a terminal at least 110 columns wide.
- **`PreModelSwitch` / `PostModelSwitch` hooks** — run hooks when the model changes; block or confirm a switch, log it, or hand the new model extra context. *(2.1.251)*
- **`--plugin-dir` takes a folder of plugins** — point it at a directory and every subfolder with a manifest loads as its own plugin, picked up mid-session without a restart. *(2.1.265)*
- **VS Code prompt box** — click the model name to switch model and effort; the `/` menu gains searchable Slash commands and Output styles entries. *(2.1.257)*

**Changed**

- **Word-editing keys match Bash by default** — `Ctrl+W` deletes back to the previous space; `Alt+F` and `Alt+D` stop at the end of the word. Previously opt-in via `keybindingFlavor`. *(2.1.261)*

**Fixed**

- **Parallel sessions keep workspace trust and MCP state** — concurrent sessions no longer overwrite each other's `~/.claude.json`, which was behind repeated trust prompts and vanishing MCP servers. *(2.1.259)*
- **`model:` and `effort:` in frontmatter** — `model:` works in interactive sessions again; `effort:` now applies on models with a pinned default effort. *(2.1.259, 2.1.267)*
- **Fewer prompt-cache misses after `/model` and `--resume`** — switching models no longer re-sends every tool definition, and resuming replays recorded tool descriptions instead of re-rendering them. *(2.1.267)*

**Also in this issue**

Desktop panes pop out into their own windows; the Files pane gains tabs and inline preview for PDFs, Office docs and spreadsheets; output styles work on desktop; SSH sessions can remember a host password. Claude Fable 5.1 is available via `claude update` then `/model fable` — more eager than Fable 5, so prompts and `CLAUDE.md` written for older models may need toning down. Computer use can run in the background on desktop without taking over cursor and keyboard (beta on Pro and Max, macOS 15+).
