# Claude Weekly

Notes kept from *This week in Claude Code*, the weekly email from the Claude Code team.

## Read it on the web

**<https://code.claude.com/docs/en/whats-new>**

This is the official archive — the weekly digest in documentation form, going back to Week 13 (March 2026). Each week has its own page:

```
https://code.claude.com/docs/en/whats-new/2026-w34
https://code.claude.com/docs/en/whats-new/2026-w33
...
```

Every entry links through to the relevant docs page.

**The archive lags the email, and has gaps.** Checked 14 September 2026: the index ended at **Week 34** (Aug 17–21) while the newsletter had already delivered **Week 37** (Sep 11–12) — `2026-w35`, `2026-w36` and `2026-w37` all returned 404. Week 31 is missing entirely, between Weeks 30 and 32, so this is not simply a publishing delay.

| Source | Currency | What it gives you |
|---|---|---|
| The email | Earliest | The digest itself, with commentary and config examples |
| [Archive](https://code.claude.com/docs/en/whats-new) | Trails by ~3 weeks, with gaps | Catching up on older weeks |

So an issue in your inbox may not be on the web at all yet — which is the reason for keeping notes here.

(Each issue also links to the [version changelog](https://code.claude.com/docs/en/changelog) for the full version-by-version detail. That is a different artifact — what changed in each release, with none of the digest's framing — not another way to read the newsletter.)

## Subscribing

The signup I can point at is the [Claude developer newsletter](https://claude.com/newsletter/developers), also linked from the [Claude Code product page](https://claude.com/product/claude-code).

One caveat worth recording: that page describes a **monthly** developer newsletter, while *This week in Claude Code* arrives **weekly** from `no-reply@email.claude.com`. They may be the same list or two different ones — that is unconfirmed. The weekly email appears to reach Claude Code users directly rather than through a public signup form. Given the archive's lag and gaps noted above, the email is currently the only way to read an issue in the week it ships.

Anthropic publishes the list of addresses its genuine marketing email comes from, useful for telling a real issue from a phish: <https://support.claude.com/en/articles/10416553-official-anthropic-marketing-email-addresses>
