## Read it on the web

**<https://code.claude.com/docs/en/whats-new>**

```
https://code.claude.com/docs/en/whats-new/2026-w34
https://code.claude.com/docs/en/whats-new/2026-w33
...
```

Every entry links through to the relevant docs page, and the [full changelog](https://code.claude.com/docs/en/changelog) carries the bug fixes and minor improvements the digest leaves out.

## Subscribing

The signup I can point at is the [Claude developer newsletter](https://claude.com/newsletter/developers), also linked from the [Claude Code product page](https://claude.com/product/claude-code).

One caveat worth recording: that page describes a **monthly** developer newsletter, while *This week in Claude Code* arrives **weekly** from `no-reply@email.claude.com`. They may be the same list or two different ones — that is unconfirmed. The weekly email appears to reach Claude Code users directly rather than through a public signup form. If the goal is simply to read every issue, the docs archive above is the reliable route and needs no subscription at all.

Anthropic publishes the list of addresses its genuine marketing email comes from, useful for telling a real issue from a phish: <https://support.claude.com/en/articles/10416553-official-anthropic-marketing-email-addresses>
